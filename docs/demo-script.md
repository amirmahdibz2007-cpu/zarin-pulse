# متن ویدئوی دمو پنج‌دقیقه‌ای

دو تکه: دسکتاپ و موبایل روی همان لینک زنده.

- `0:00–0:20` موبایل. آیکون نصب‌شده روی صفحه اصلی. یک جمله: همین محصول روی گوشی و دسکتاپ یکی است.
- `0:20–1:00` دسکتاپ. آناتومی رهاشدن. شکست فنی ۱٫۵٪؛ ۳۵٫۶٪ صفحه بانک؛ ۱۲٫۸٪ قبل از بانک.
- `1:00–1:35` دسکتاپ. M91 و M282. دو الگوی درگاه شکسته.
- `1:35–2:10` دسکتاپ. M31. نوار سه‌ارزی. ارزها جمع نمی‌شوند.
- `2:10–2:50` دسکتاپ. کارمزد و M106. کف ۱٬۹۲۰ ریال.
- `2:50–3:20` دسکتاپ. PSP و سیمپسون.
- `3:20–3:45` دسکتاپ. منحنی بقا. تلاش دوم ۴۱٫۷٪.
- `3:45–4:15` دسکتاپ. Passport و `/reconciliation`.
- `4:15–4:45` موبایل. همان صفحه پذیرنده تک‌ستونی.
- `4:45–5:00` موبایل. حالت پرواز؛ اپ همچنان کار می‌کند.
