# زرین‌پالس (ZarinPulse)

پلتفرم تحلیلی هوشمند و تصمیم‌یار مالی برای پذیرندگان زرین‌پال: تشخیص دقیق نقاط رهاشدن پرداخت، محاسبه حجم فروش قابل بازیابی، و تحلیل ریشه‌ای سهم و فشار کارمزد.

تمامی اعداد و بینش‌ها از داده‌های واقعی استخراج شده و مجهز به گذرنامه شواهد (Evidence Passport) جهت ردیابی کامل و راستی‌آزمایی آماری هستند.

### مسیر ۲ — راهنمای بررسی ۵ دقیقه‌ای داور (Quick Tour)

برای بررسی متمرکز مهم‌ترین قابلیت‌ها و بینش‌های محصول، مسیر زیر پیشنهاد می‌شود:

1. **مسیر داور (`/judge`):** بررسی دسته‌بندی پذیرندگان شاخص و میان‌برهای تحلیلی.
2. **پذیرنده M31 (`/m/M31` یا داشبورد اصلی):** مشاهده بزرگ‌ترین فرصت بازیابی فروش، تحلیل لایه‌بندی مشتریان (طلا، نقره، برنز، در خطر) و اسلایدر شبیه‌ساز اثر انصراف.
3. **درگاه شکسته M91 (`/m/M91` و `/health`):** تشخیص خودکار پذیرنده‌ای که ۱۰۰٪ ریزش آن پیش از رسیدن به بانک رخ می‌دهد.
4. **تحلیل فشار کارمزد (`/fees` و M106):** بررسی اثر تله کف کارمزد ثابت روی تراکنش‌های خرد و تفکیک اثر اندازه سبد از تعرفه.
5. **مسیریابی پرداخت‌یارها (`/psp`):** بررسی عملکرد PSPها و کنترل خطای پارادوکس سیمپسون در سهم تراکنش‌ها.
6. **دستیار تحلیلی هوش مصنوعی (`/ai` و `/ask`):** تحلیل متنی خودکار و گفتگو پیرامون وضعیت و اقدامات پیشنهادی هر پذیرنده.
7. **کنترل و تطبیق اعداد (`/reconciliation`):** راستی‌آزمایی صحت تمامی محاسبات و اتحادهای حسابداری در سطح کلان داده.

### مسیر ۳ — اجرای محلی (Local Development)

پروژه به هیچ پایگاه داده خارجی، پایتون یا داکر نیاز ندارد و کلیه آرتفکت‌ها از پیش محاسبه و کامیت شده‌اند.

**پیش‌نیاز:** Node.js نسخه ۲۲ یا بالاتر

```bash
# ۱. دریافت کد
git clone https://github.com/amirmahdibz2007-cpu/zarin-pulse.git
cd zarin-pulse

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه
npm run dev
```

پس از اجرا، آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

#### اجرای بیلد تولیدی (Production Build):
```bash
npm run build
npm start
```

## راستی‌آزمایی و کیفیت کد (Verification)

برای اطمینان از سلامت کامل ساختار پکیج‌ها، تایپ‌ها، تست‌ها و گاردهای زبان فارسی:

```bash
npm run verify
```

این فرمان شامل موارد زیر است:
- **Typecheck کامل با TypeScript**
- **لینتینگ استاندارد با ESLint**
- **اجرای تمامی تست‌های واحد و آماری با Vitest** (۱۲۷ تست فعال)
- **گاردهای عدم نشت اصطلاحات فنی به زبان کاربر و بررسی PWA**
- **تست سازگاری در خط لوله CI روی Windows و Linux**

## نکات کلیدی درباره داده‌ها

- واحد کلیه مبالغ ارائه‌شده **ریال** است.
- ستون `adjusted_fee` برای حفظ محرمانگی داده‌ها دارای ضریب بوده و صرفاً جهت مقایسه نسبی به کار می‌رود، نه کارمزد قطعی و واقعی.
- معماری سیستم به‌صورت ماژولار و Monorepo با تفکیک دقیق لایه‌های `contracts` ،`analytics` ،`etl` ،`calendar` ،`insights` و `web` طراحی شده است.
